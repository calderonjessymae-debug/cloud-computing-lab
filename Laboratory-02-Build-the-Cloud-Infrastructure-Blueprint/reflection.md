# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think **compute resources** are the most important cloud infrastructure component because they provide the processing power needed to run applications and services. In the KillerCoda environment, the server had an Intel Xeon CPU with one CPU core and approximately 1.9 GiB of RAM. Without compute resources, the operating system and applications would not be able to perform their tasks.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable operating system for cloud servers and virtual machines. During this laboratory, I used Linux commands to investigate the operating system, kernel, CPU, RAM, storage, mounted file systems, hostname, and IP address. Linux also provides many tools that help administrators manage and monitor cloud environments.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure, configurations, resources, and design. It helps engineers understand what needs to be deployed and reduces the possibility of mistakes. Good documentation also makes troubleshooting and future maintenance easier.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud server using terminal commands. I learned how to identify compute, storage, networking, and operating system resources. I also learned how to compare AWS, Microsoft Azure, and Google Cloud Platform services and create a simple cloud infrastructure diagram. In addition, I improved my Markdown and GitHub documentation skills.
