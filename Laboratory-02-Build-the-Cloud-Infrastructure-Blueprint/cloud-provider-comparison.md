# Cloud Provider Comparison

## Checkpoint 4 – Research the Major Cloud Providers

Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP) are three major public cloud providers. They provide similar core infrastructure services, although each provider uses different service names and features.

## Cloud Infrastructure Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS Identity and Access Management (IAM) | Microsoft Entra ID and Azure RBAC | Cloud Identity and Access Management (IAM) |

---

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS offers one of the broadest ranges of cloud services among the three providers. It provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, and many other cloud needs.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure for an organization that primarily uses Microsoft products. Azure integrates well with Microsoft technologies and services, making it easier for organizations already using products such as Windows Server, Microsoft Entra ID, and other Microsoft services.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its strengths in Artificial Intelligence, Machine Learning, and Kubernetes. Google Cloud provides AI and ML services and offers Google Kubernetes Engine (GKE), a managed Kubernetes service.

### 4. What similarities did you observe among the three cloud providers?

The three cloud providers offer similar core infrastructure services, including compute, storage, networking, and identity and access management. They also provide scalable resources, security features, monitoring tools, and services that allow organizations to build and manage cloud-based applications.

## Conclusion

AWS, Microsoft Azure, and Google Cloud Platform provide equivalent core infrastructure services but use different names and approaches. Understanding these equivalents helps cloud engineers select the appropriate provider and understand how infrastructure concepts transfer between cloud platforms.
